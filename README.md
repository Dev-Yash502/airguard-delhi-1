# AirGuard Delhi

AirGuard Delhi is a lightweight web application that helps users understand air pollution levels in different areas of Delhi.

Users select their area, and the system displays air quality status (Safe, Moderate, or Dangerous) along with health and safety suggestions.

## Features
- Area-wise air quality awareness
- Color-coded AQI status (Green, Yellow, Red)
- Health and safety recommendations
- Simple and user-friendly UI

## Tech Stack
- Frontend: HTML, Tailwind CSS, JavaScript
- Backend: Python, Flask

## Google Technologies Used
- Google Drive (demo video hosting)
- Google Charts / Google Maps (planned for future integration)

## How to Run Backend
1. Navigate to backend folder
2. Run: `python app.py`
3. Open browser and visit:
   http://127.0.0.1:5000/predict?area=Anand Vihar
