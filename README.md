# 🌍 AirGuard Delhi

AirGuard Delhi is a hackathon prototype designed to raise awareness about air pollution across different areas of Delhi. The project demonstrates how technology can provide simple, location-based air quality insights and health recommendations to users.

## 🚀 Live Demo

**Frontend (Netlify):**
https://magical-cat-c6c226.netlify.app/

## 📖 About The Project

AirGuard Delhi was developed as a proof-of-concept during a hackathon. The goal was to create a simple platform where users could select a Delhi locality and instantly view air quality information along with basic health and safety suggestions.

This project is intended for learning, demonstration, and portfolio purposes.

## ✨ Features

* Area-wise air quality awareness
* AQI status categorization
* Personalized safety recommendations
* Responsive user interface
* Lightweight Flask backend

## 🔧 Running Locally

```bash
cd backend
pip install flask flask-cors
python app.py
```

Example API request:

```text
http://127.0.0.1:5000/predict?area=Dwarka
```
